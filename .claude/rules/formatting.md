# Formatting Guidelines (ESE Capstone Standard)

1. **Document Format:** 1.5 line-spaced, 12-point Times New Roman font.
2. **Headings:** Outline numbered (e.g., 1. Introduction, 1.1 Purpose).
3. **Figures:** Number and title go BELOW the figure (e.g., "Figure 1: PortaPill System Block Diagram"). Must be referenced in text before appearing.
4. **Tables:** Number and title go ABOVE the table (e.g., "Table 1: MoSCoW Requirements"). Must be referenced in text before appearing.
5. **Citations:** IEEE Style exclusively. Example: [1], [2]. Every claim derived from literature must be cited.
6. **Acronyms:** Define upon first use (e.g., Non-Volatile Storage (NVS)).
