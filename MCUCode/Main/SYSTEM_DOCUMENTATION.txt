================================================================================
                                SYSTEM OVERVIEW
================================================================================

This is a prototype automated pill dispensing system with multi-medication 
profile management, motor control, and sensor-based feedback for accurate 
pill dispensing operations.

Key Components:
- Raspberry Pi Pico 2 microcontroller
- PWM-controlled motor with direction control
- Three-sensor interrupt system (Piezo, Hall Effect, IR)
- USB serial interface for control and debugging
- Multi-profile medication management

================================================================================
                                MOTOR CONTROL SYSTEM
================================================================================

Hardware Configuration:
- PWM Output: GPIO 0 (speed control)
- Direction Control: GPIO 1 (DIR_PIN1), GPIO 2 (DIR_PIN2)
- PWM Resolution: 4 steps (0-3) for fine motor control
- Motor Speed: Configurable via MOTOR_SPEED constant

Motor Operations:
✓ FORWARD:  DIR_PIN1=HIGH, DIR_PIN2=LOW, PWM=ON
✓ BACKWARD: DIR_PIN1=LOW, DIR_PIN2=HIGH, PWM=ON  
✓ STOP:     Both pins LOW, PWM=OFF

Available Functions:
- motor_init() - Initialize PWM and GPIO
- motor_forward() - Rotate motor forward
- motor_backward() - Rotate motor backward
- motor_stop() - Stop motor immediately
- motor_set_direction(direction) - Set direction via enum

Manual Control Commands:
- 'W' key: Manual motor forward
- 'X' key: Manual motor stop

================================================================================
                            SENSOR INTERRUPT SYSTEM
================================================================================

Three-Sensor Architecture:
1. PIEZO SENSOR (GPIO 5)
   - Detects pill drops/vibrations
   - Voltage: 1V rest → 3.3V active (voltage divider protected)
   - Edge Detection: Both rising and falling
   - Debounce: 50ms
   - Purpose: Pill drop detection

2. HALL EFFECT SENSOR (GPIO 6)  
   - Detects motor position via magnetic field
   - Voltage: 3.3V active (voltage divider protected)
   - Edge Detection: Both rising and falling
   - Debounce: 100ms
   - Purpose: Motor position tracking

3. IR SENSOR (GPIO 7)
   - Detects beam break/restore events
   - Logic: Active low (beam broken = LOW)
   - Edge Detection: Both rising and falling
   - Debounce: 50ms
   - Purpose: Pill passage detection

Interrupt System Features:
✓ Unified GPIO interrupt handler (fixes SDK callback limitation)
✓ Individual sensor enable/disable control
✓ Hardware debouncing with configurable timing
✓ Detailed debug output with timing information
✓ Callback system for user-defined responses

Sensor Control Commands:
- 'P': Toggle piezo sensor on/off
- 'H': Toggle hall effect sensor on/off
- 'I': Toggle IR sensor on/off
- 'R': Reset all sensor counters
- 'T': Display sensor status and counts

Profile Operations:
